# Current public roadmap

Deutsch: [ROADMAP_DE.md](ROADMAP_DE.md)

Reviewed: **November 1, 2026**. The following acceptance criteria remain open; existing implementation is not described as missing.

| Area | Existing progress | Evidence still needed |
|---|---|---|
| Installation / runtime | Current installation binding and health projection in source | Loaded-source identity, complete natural service cycles and repeatable recovery |
| Market inputs | Readers and scoped error handling present | Sustained freshness and a time-aligned source→reader→decision chain |
| WebUI | Trade readers and refresh-state preservation present | Same-snapshot API-to-display acceptance; filters, selection and scroll in the current browser |
| Learning | Decision/outcome recording and later consumers present | Natural later same-identity decision effect and independent after-cost benefit |
| External AI | Request/response/context and budget handling progressed | Loaded-source parity, natural valid consumer/outcome chain and matched economic quality |
| Research / ML | Research and comparison paths present | Independent matched OOS/holdout evaluation; no automatic training or promotion mandate |
| Costs | Incomplete evidence remains explicitly qualified | Complete natural execution and holding costs for each affected population |
| Storage | Logical handling present | Separate growth, migration, retention and physical-shrink evidence |
| Demo / release | Earlier scoped access checks | Connected Demo/Testnet E2E and reproducible installation, update and recovery |

Current configuration disables live execution, real-capital use and training. Source progress does not automatically close a product criterion. Full release/manifest parity remains open.

## November 3 addition

Additional acceptance needs cover complete adoption of the new candidate/cost checks by affected processes, a complete new Gemini request/storage path, consistent modeled-cost presentation, and independent economic evaluation. Storage deduplication is not physical shrink. [New update](../../updates/2026-11-03-public-status.md).


## November 13 clarification

Release notes through v90.8.5.23 R3 document improvements to contract compatibility, history consistency, interrupted-state recovery, workflow attribution, snapshot-based metrics, runtime warnings and package integrity. These documented changes do not close the open acceptance criteria in the table: loaded-service identity, complete natural cycles, full browser acceptance, independent economic benefit and reproducible release/recovery evidence remain separate. [Documentation update](../../updates/2026-11-13-public-status.md).
