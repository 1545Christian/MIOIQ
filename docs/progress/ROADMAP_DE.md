# Aktuelle öffentliche Roadmap

English: [ROADMAP.md](ROADMAP.md)

Abgleich: **1. November 2026**. Die folgenden Kriterien sind offen; vorhandene Implementierung wird nicht als fehlend dargestellt.

| Bereich | Vorhandener Fortschritt | Noch benötigter Nachweis |
|---|---|---|
| Installation / Runtime | Aktuelle Installationsbindung und Health-Projektion im Code | Geladene Quellen, vollständige natürliche Servicezyklen und wiederholbare Recovery |
| Markteingaben | Reader und begrenzte Fehlerbehandlung vorhanden | Dauerhafte Frische und zeitlich passende Quelle→Reader→Entscheidung-Kette |
| WebUI | Trade-Reader und Refresh-Zustandserhaltung vorhanden | Gleicher Snapshot von API bis Darstellung; Filter, Auswahl und Scrollposition im aktuellen Browser prüfen |
| Learning | Decision-/Outcome-Erfassung und spätere Consumer vorhanden | Natürliche spätere Entscheidungswirkung mit gleicher Identität und unabhängiger Nutzen nach Kosten |
| Externe KI | Request-/Antwort-/Kontext- und Budgetpfad weiterentwickelt | Geladene Quellenparität, natürliche gültige Consumer-/Outcome-Kette und gematchte wirtschaftliche Qualität |
| Research / ML | Research- und Vergleichspfade vorhanden | Unabhängige gematchte OOS-/Holdout-Auswertung; kein automatischer Trainings-/Promotionauftrag |
| Kosten | Unvollständige Belege werden ausdrücklich begrenzt | Vollständige natürliche Ausführungs- und Haltekosten je betroffener Population |
| Storage | Logische Verarbeitung vorhanden | Wachstum, Migration, Retention und physischer Shrink jeweils separat nachweisen |
| Demo / Release | Begrenzte frühere Zugangsprüfungen | Connected Demo/Testnet E2E sowie reproduzierbare Installation, Update und Wiederherstellung |

Die aktuelle Konfiguration deaktiviert Live-Ausführung, Echtgeldnutzung und Training. Quellenfortschritt schließt kein Produktkriterium automatisch. Vollständige Release-/Manifest-Parität bleibt offen.
