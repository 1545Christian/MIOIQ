## Open or not proven

- complete loaded-service and recovery acceptance
- sustained freshness and full current instrument coverage
- full current WebUI acceptance
- natural later learning effect with independent after-cost benefit
- fair matched model/strategy/AI comparisons and final holdout
- complete natural execution and holding costs
- current physical database shrink
- Connected Demo/Testnet execution/recovery E2E
- current release/manifest parity and reproducible update/rollback acceptance
- profitability or live readiness

## Evidence layers

Source → focused tests → loaded runtime → completed consumer → browser acceptance → economic evaluation.

No layer automatically proves the next. Syntactically valid AI output, a NO_TRADE decision or a stored learning link does not establish economic benefit.
